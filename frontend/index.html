Pipeline

How It Works

A four-step scientific pipeline from molecular structure to classification.

1
SMILES Input

The user inputs the chemical structure as a SMILES string.

2
Morgan Fingerprint

RDKit converts SMILES into a 2048-bit circular fingerprint encoding chemical features.

3
Saved Best Model

The automatically selected best classifier evaluates the fingerprint vector.

4
Real-Time Result

Returns Active or Inactive with a confidence probability score.

About

About This Project

Problem Statement

In early-stage drug discovery, identifying chemical compounds that can bind to and inhibit a specific disease target protein (such as the Cyclooxygenase-2 (COX-2) enzyme responsible for inflammation and pain) is a major challenge. Traditional wet-lab synthesis and biological testing of thousands of candidate molecules is extremely time-consuming, labor-intensive, and expensive.

What This Project Does

This project provides an automated, machine-learning-based virtual screening tool. A user provides a chemical molecule's text representation as a SMILES string. Using RDKit, the structure is converted into a 2048-bit Morgan circular fingerprint that encodes the molecule's unique chemical substructures.

Our trained XGBoost classifier analyzes these numerical features and predicts whether the compound is biologically Active or Inactive against the target, providing an associated confidence score to help researchers quickly shortlist potential drug candidates.
